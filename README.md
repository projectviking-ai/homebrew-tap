# Project Viking Homebrew Tap

Homebrew formulae for Project Viking open-source tools.

## Availability

No formulae have been published yet. Install commands will be added here as packages become available.

## Existing Valdr users

Continue using [projectviking-ai/homebrew-valdr](https://github.com/projectviking-ai/homebrew-valdr). That tap remains separate; no migration to this tap is required.

## Distribution

This repository contains formulae and documentation. Compiled binaries are downloaded from versioned release assets and verified using checksums; they are not committed to this repository.
